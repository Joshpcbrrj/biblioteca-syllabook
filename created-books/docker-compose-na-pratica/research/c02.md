# Dossiê c02 · Instalar e conferir o Compose

## Fatos (conferidos em 2026-11-20)
- Docker Desktop inclui o Compose; "the easiest and recommended way" — https://docs.docker.com/compose/install/
- Plugin no Linux: pacote `docker-compose-plugin`; `sudo apt-get install docker-compose-plugin` ou `sudo yum install docker-compose-plugin` — https://docs.docker.com/compose/install/linux/
- Instalação standalone: legada, não recomendada — https://docs.docker.com/compose/install/
- Instalação manual não se atualiza; o exemplo da página fixa v5.6.0 — https://docs.docker.com/compose/install/linux/
- Verificar: `docker compose version` (a página não mostra saída). Saída real local (nova referência): `Docker Compose version v5.7.0`; `--short` -> `5.7.0`
- Docker Desktop: "The easiest and recommended way"; versão do Compose em About Docker Desktop — https://docs.docker.com/compose/install/ (2026-11-20)
- Máquina do autor (Windows 11): Docker Desktop 4.99.0, Client/Engine 29.9.3, plugin em `C:\Users\<usuário>\.docker\cli-plugins\docker-compose.exe` (`docker info`)
- Mais novas em 2026-11-20: Compose v5.8.0 (2026-11-17, https://github.com/docker/compose/releases); Engine 29.10.0 (2026-11-16, https://docs.docker.com/engine/release-notes/). Referência do livro: Compose v5.7.0 / Engine 29.9.3 (mudança de 2026-11-20)

## Teste no Linux (contêiner ubuntu:24.04, repositório oficial da Docker, 2026-11-20)
- Só `docker-ce-cli` instalado: `docker compose version` -> `docker: unknown command: docker compose` + `Run 'docker --help' for more information`; `docker-compose` -> `command not found`
- `apt-cache madison docker-compose-plugin`: 5.8.0, 5.7.2, 5.7.1, ... (formato `5.7.0-1~ubuntu.24.04~noble`)
- `apt-get install docker-compose-plugin=5.7.0-1~ubuntu.24.04~noble` -> `Docker Compose version v5.7.0`; instala junto docker-buildx-plugin

- `apt-get install docker-compose-plugin` sem versão atualiza para v5.8.0
