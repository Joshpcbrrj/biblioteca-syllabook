# Dossiê c04 · Build pelo Compose

## Fatos (conferidos em 2026-11-20) — https://docs.docker.com/reference/compose-file/build/
- `build: .` ou forma longa com `context` (pasta ou URL Git; relativo ao diretório do projeto; padrão `.`)
- `dockerfile`: relativo ao context; não combina com `dockerfile_inline`
- `args`: mapa ou lista (`GIT_COMMIT: cdc3b19`)
- Também: `target`, `labels`, `platforms`, `cache_from`, `no_cache`
- Reconstruir: `docker compose up --build` ou `docker compose build` — https://docs.docker.com/reference/cli/docker/compose/up/

## Erros comuns
- Mudar o código e rodar só `up` (a imagem antiga é reutilizada)
- `image` + `build` juntos: conferir ao escrever o nome que a imagem recebe
