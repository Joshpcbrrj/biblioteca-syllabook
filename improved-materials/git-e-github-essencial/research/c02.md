# Dossiê c02: Instalação, identidade e credenciais

Original: Instalando e configurando o Git; Registrando usuários locais e credenciais (+ extra "chave SSH" do repositório do curso).

## Fatos (checados em 2026-11-21)

- Versão atual: 2.56.1 nas páginas de instalação. https://git-scm.com/install/windows · /install/mac · /install/linux
- Windows: instalador do Git para Windows (inclui Git Bash e Git Credential Manager); alternativa `winget install --id Git.Git -e --source winget` (a página diz que o winget não é mantido pelo projeto). macOS: `brew install git` (também MacPorts, Xcode Command Line Tools). Debian/Ubuntu: `apt-get install git`.
- Níveis de config: `--system` ($(prefix)/etc/gitconfig), `--global` (~/.gitconfig ou $XDG_CONFIG_HOME/git/config), `--local` (.git/config; padrão ao gravar). Docs locais git-config (Git 2.56).
- `--show-origin` mostra de onde vem cada valor. git-config.
- `credential-cache --timeout` padrão 900 s; socket Unix. git-credential-cache.
- `credential.helper store` grava em `~/.git-credentials` em texto puro. git-credential-store.
- GitHub não aceita senha da conta em operações Git desde 13/08/2021. https://github.blog/security/application-security/token-authentication-requirements-for-git-operations/
- GCM "is included with Git for Windows"; "runs on Windows, macOS, and Linux". https://github.com/git-ecosystem/git-credential-manager
- SSH: `ssh-keygen -t ed25519 -C "email"`; `ssh -T git@github.com` responde "Hi USERNAME! You've successfully authenticated, but GitHub does not provide shell access." https://docs.github.com/en/authentication/connecting-to-github-with-ssh/testing-your-ssh-connection
- E-mail noreply: `ID+USERNAME@users.noreply.github.com` (contas desde 18/07/2017). O GitHub liga o commit à conta pelo e-mail da config local, que precisa estar cadastrado na conta. https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-personal-account-on-github/managing-email-preferences/setting-your-commit-email-address
- Branch padrão de repositórios novos no GitHub: `main`, desde 01/10/2020. https://github.blog/changelog/2020-10-01-the-default-branch-for-newly-created-repositories-is-now-main/

## Exemplos novos

- Pessoa com e-mail pessoal global e o e-mail de uma ONG onde é voluntária num só repositório.

## Erros comuns

- Achar que `user.name` é login.
- Usar `store` ou token na URL.
- E-mail do commit não cadastrado no GitHub: commits não aparecem no perfil.
- `core.editor "code"` sem `--wait`: o Git não espera o editor (testar a mensagem real).
