# Dossiê c10: Projeto currículo online

Original: as aulas do projeto do currículo (publicação no Pages e extensões de Git no VS Code), de Markdown e de gists.

## Fatos a confirmar ao escrever (fontes oficiais listadas em 2026-11-21)

- GitHub Pages: site de usuário no repositório `<usuario>.github.io`; publicação a partir de uma branch (raiz ou /docs) ou por GitHub Actions. https://docs.github.com/pt/pages/getting-started-with-github-pages
- Markdown do GitHub: títulos, listas, tabelas, blocos de código com linguagem, listas de tarefas, alertas `> [!NOTE]`. https://docs.github.com/pt/get-started/writing-on-github
- README de perfil: repositório com o mesmo nome do usuário. https://docs.github.com/pt/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme
- Gists públicos e secretos (secreto não é privado: quem tem o link vê). https://docs.github.com/pt/get-started/writing-on-github/editing-and-sharing-content-with-gists/creating-gists
- VS Code: painel Source Control; capturas pedidas ao usuário.
