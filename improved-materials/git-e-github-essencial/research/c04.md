# Dossiê c04: Commits e histórico

Original: Como fazer os commits; Como consultar o histórico; Comandos úteis; Consultando histórico de commits.

## Fatos (checados em 2026-11-21; docs locais do Git 2.56)

- `git log --oneline` = `--pretty=oneline --abbrev-commit`; `--graph`; `--author=<pattern>`; `-p`; `--stat`; `-n`; `--since`. git-log.
- `git show <commit>`; `git diff` (trabalho × staging); `git diff --staged` (staging × HEAD). git-diff.
- `HEAD~1`, `HEAD~2`, `HEAD^`. gitrevisions.
- `git blame <arquivo>`. git-blame.
- Mensagem: resumo curto (~50 caracteres), linha em branco, corpo explicando o porquê. https://git-scm.com/book/en/v2/Distributed-Git-Contributing-to-a-Project

## Exemplos

- Commits do `receitas`: adiciona o bolo, corrige o tempo de forno, ajusta o título.

## Erros comuns

- Commits gigantes ("várias mudanças").
- `git commit -am` não inclui arquivos novos (untracked).

## Ponte

- O cap. 5 depende de HEAD e HEAD~n.
