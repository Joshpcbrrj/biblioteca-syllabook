# Dossiê c06: Branches, stash e merge

Original: Branches; Guardando trabalho com git stash; Merge; Resolvendo conflitos.

## Fatos (checados em 2026-11-21; docs locais do Git 2.56)

- Branch = ponteiro móvel para um commit; criar é barato. https://git-scm.com/book/en/v2/Git-Branching-Branches-in-a-Nutshell
- `git switch -c`; `git branch -d` (só se já mesclada), `-D` força.
- `git stash`, `-u` (inclui untracked), `list`, `pop`, `apply`, `drop`. git-stash.
- Fast-forward × merge de três vias (commit de merge com dois pais). https://git-scm.com/book/en/v2/Git-Branching-Basic-Branching-and-Merging
- Marcadores `<<<<<<<`, `=======`, `>>>>>>>`; `merge.conflictStyle` padrão "merge" (há diff3 e zdiff3); `git merge --abort`. git-config, git-merge.

## Exemplos

- Branch `sobremesas` no `receitas`; conflito no tempo de forno do bolo.

## Erros comuns

- Trocar de branch com alterações não commitadas.
- Commitar com os marcadores de conflito no arquivo.
