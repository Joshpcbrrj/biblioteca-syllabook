# Dossiê c07: Rebase e histórico limpo

Original: Rebase.

## Fatos (checados em 2026-11-21; docs locais do Git 2.56)

- O rebase reaplica commits com hashes novos; regra: não fazer rebase de commits que existem fora do seu repositório e sobre os quais outras pessoas podem ter trabalhado. https://git-scm.com/book/en/v2/Git-Branching-Rebasing
- `--continue`, `--skip`, `--abort`; `rebase -i` com pick, reword, edit, squash, fixup, drop. git-rebase.
- `pull.rebase=true` faz o pull com rebase. git-config.

## Erros comuns

- Rebase de branch compartilhada.
- Esquecer o `git add` antes do `--continue`.
- Recuperação: `git reflog` e `ORIG_HEAD`.
