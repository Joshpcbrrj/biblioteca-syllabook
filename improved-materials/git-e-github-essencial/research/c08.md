# Dossiê c08: Repositórios remotos

Original: Bare repository; Clone e push; Fetch e pull; Repositório remoto no GitHub; Usando clone e pull; Trabalhando com tags.

## Fatos (checados em 2026-11-21; docs locais do Git 2.56)

- `git init --bare`; `git clone`; `git remote add`, `git remote -v`; `git push -u origin main`. git-init, git-clone, git-remote, git-push.
- `push.autoSetupRemote`: assume `--set-upstream` quando a branch não tem upstream. git-config. (Conferir nas release notes a versão em que surgiu, ao escrever.)
- `fetch` atualiza `origin/main` sem mexer na branch local; `pull` = fetch + merge (ou rebase). git-pull.
- Tags leves × anotadas (`-a -m`); o push não envia tags por padrão: `git push origin <tag>` ou `--tags`. https://git-scm.com/book/en/v2/Git-Basics-Tagging
- `--force-with-lease` como alternativa segura ao `--force`. git-push.
- Releases do GitHub a partir de tags. https://docs.github.com/pt/repositories/releasing-projects-on-github/about-releases (abrir ao escrever)
