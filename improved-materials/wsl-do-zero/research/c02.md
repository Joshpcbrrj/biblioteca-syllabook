# Dossiê cap. 2: Instalação do WSL e do Ubuntu (conferido em 2026-11-27)
- `wsl --install` (PowerShell como administrador, depois reiniciar) ativa os componentes e instala Ubuntu por padrão; só funciona se o WSL não estiver instalado; se aparecer a ajuda, usar `wsl --list --online` e `wsl --install -d <Distro>`. Se travar em 0.0%: `wsl --install --web-download -d <Distro>`. https://learn.microsoft.com/windows/wsl/install (2026-11-27)
- Distros online conferidas hoje (`wsl --list --online`): Ubuntu, Ubuntu-26.04, Ubuntu-24.04, Ubuntu-22.04, openSUSE, Debian, kali-linux, AlmaLinux etc. (2026-11-27)
- Imagem .wsl do Ubuntu 26.04.1: https://releases.ubuntu.com/26.04.1/ubuntu-26.04.1-wsl-amd64.wsl (399 MiB), SHA256 48d56724b5c8e60f24893e83e73bbb58c60b3ca22fba3da977075420acd54104, igual ao DistributionInfo.json do repositório microsoft/WSL (2026-11-27).
- Primeira abertura: descompacta e pede usuário (minúsculas) e senha; o uid do primeiro usuário costuma ser 1000.
- `wsl -l -v` mostra NAME/STATE/VERSION (VERSION 2); `wsl --version` mostra WSL 3.0.5.0, kernel, WSLg etc. `wsl --status`: distro e versão padrão. `wsl --set-version <Distro> 2`, `wsl --set-default-version 2`, `wsl -s <Distro>`.
- Instalação offline: MSI do GitHub + `dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart` + arquivo .wsl.
- Erros comuns (troubleshooting oficial, a conferir caso a caso): virtualização desabilitada no firmware (erro 0x80370102), componente Plataforma de Máquina Virtual desativado, falta de internet/Store, disco cheio.
