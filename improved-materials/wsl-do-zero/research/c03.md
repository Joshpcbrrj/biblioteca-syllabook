# Dossiê cap. 3: Primeiros passos no Ubuntu (conferido em 2026-11-27)
- No Ubuntu 26.04 do WSL: systemd é o padrão; para outras distros `[boot] systemd=true` em /etc/wsl.conf + reiniciar a distro; verificar com `systemctl status` ou `ps -p 1 -o comm=`. https://learn.microsoft.com/windows/wsl/systemd (2026-11-27)
- Na wz-teste: `systemctl is-system-running` = degraded (importada, sem rede/usuário); anotar a saída real no cap.
- apt: `apt update` (lista), `apt upgrade`, `apt install/remove`; `apt list --upgradable`. Ubuntu 26.04: apt 3.x (a conferir no lab com `apt --version`).
- sudo × root: usuário comum no grupo sudo (uid 1000); `sudo` pede a senha do usuário; no 26.04 o sudo é o sudo-rs? (CONFERIR: Ubuntu 25.10+ trocou por sudo-rs); asteriscos na senha.
- Boas práticas Microsoft: https://learn.microsoft.com/windows/wsl/setup/environment (2026-11-27): guardar projeto no sistema de arquivos do Linux; Windows Terminal; git.
- Repositório do projeto: git no Ubuntu 26.04 (versão a conferir); `git init`, `git config` só dentro do repo/HOME temporário.
- Erro comum: trabalhar sempre como root; esquecer apt update antes de install ("Unable to locate package").
