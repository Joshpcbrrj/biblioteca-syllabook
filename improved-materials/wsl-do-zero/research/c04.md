# Dossiê cap. 4: Arquivos entre Linux e Windows (conferido em 2026-11-27)
- Discos do Windows aparecem em `/mnt/c`, `/mnt/d`; os arquivos do Linux aparecem no Windows em `\\wsl$\<distro>` (e `\\wsl.localhost\<distro>`). `explorer.exe .` abre a pasta atual no Explorer. https://learn.microsoft.com/windows/wsl/filesystems (2026-11-27)
- Recomendação oficial: para velocidade, guardar os arquivos no sistema de arquivos do WSL ao trabalhar numa linha de comando Linux; não em /mnt/c. (2026-11-27)
- `wslpath` converte caminhos (-w para Windows, -u para Linux); testar no lab.
- Opções de automount (wsl.conf `[automount]`): `enabled`, `root` (padrão /mnt/), `options` (metadata, umask, fmask...), `mountFsTab`. https://learn.microsoft.com/windows/wsl/wsl-config (2026-11-27)
- CRLF × LF: git `core.autocrlf`, `.gitattributes` com `* text=auto` e `*.sh text eol=lf`; erro típico ao rodar .sh salvo com CRLF: `$'\r': command not found`. Reproduzir no lab.
- Desempenho: medir uma operação (criar 2000 arquivos) em ~ e em /mnt/d/wz-temp, com tempos reais; só na wz-teste, nunca no C:.
- Erro comum: projeto em /mnt/c.
