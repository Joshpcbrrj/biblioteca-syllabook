# Dossiê cap. 9: Claude Code no WSL (conferido em 2026-11-27)
- Instalar no WSL: `curl -fsSL https://claude.ai/install.sh | bash`; binário em ~/.local/bin/claude; `claude --version` e `claude doctor`. Claude Code v2.1.332 (25/11/2026). Requer Ubuntu 20.04+; WSL 2 suportado, WSL 1 sem sandbox. https://code.claude.com/docs/en/setup (2026-11-27)
- Modos de permissão: default, acceptEdits, plan, auto, dontAsk, bypassPermissions; Shift+Tab alterna; bypass só em contêiner/VM isolados. https://code.claude.com/docs/en/permission-modes (2026-11-27)
- Plugins: `/plugin install commit-commands@claude-plugins-official`, `claude plugin list`; plugin pode ter hooks e MCPs: ler antes. https://code.claude.com/docs/en/discover-plugins (2026-11-27)
- MCP: `claude mcp add --transport http <nome> <url>`; stdio: `claude mcp add ... -- <comando>`. https://code.claude.com/docs/en/mcp (2026-11-27)
- Login e tela de confiança: interativos, "não executado". Nunca colar tokens no chat.
