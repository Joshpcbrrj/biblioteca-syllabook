# Dossiê c03: Instalar no Linux e no Mac
Conferido em 2026-11-26.

## Fatos
- Ubuntu suportadas: 26.10, 26.04 LTS, 24.04 LTS, 22.04 LTS (64 bits). Arquiteturas: x86_64, armhf, arm64, s390x, ppc64el. Derivadas (Mint) não são oficialmente suportadas. https://docs.docker.com/engine/install/ubuntu/ (2026-11-26)
- Remover pacotes não oficiais: `docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc` (comando `sudo apt remove $(dpkg --get-selections ... | cut -f1)`).
- Repositório apt: chave em `/etc/apt/keyrings/docker.asc`, arquivo `/etc/apt/sources.list.d/docker.sources` (formato deb822: Types, URIs https://download.docker.com/linux/ubuntu, Suites, Components stable, Architectures, Signed-By), depois `sudo apt update`.
- Pacotes: `docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin`. Verificar: `sudo systemctl status docker`; `sudo docker run hello-world`.
- Firewall: portas publicadas ignoram regras do ufw/firewalld; Docker só é compatível com iptables-nft e iptables-legacy.
- Pós-instalação: `sudo groupadd docker`; `sudo usermod -aG docker $USER`; sair e entrar (ou `newgrp docker`); o grupo `docker` concede privilégios de root. Erro de `~/.docker/config.json` com permissão negada se já usou sudo: `chown`/`chmod`. https://docs.docker.com/engine/install/linux-postinstall/ (2026-11-26)
- Mac: Docker.dmg → arrastar para Applications; macOS atual e as duas anteriores; 4 GB RAM; Rosetta 2 recomendada, não mais obrigatória (`softwareupdate --install-rosetta`); aceitar o acordo; sem pedir senha. https://docs.docker.com/desktop/setup/install/mac-install/ (2026-11-26)
- Desktop existe também para Linux (Debian, RPM, Arch nas notas de versão). https://docs.docker.com/desktop/release-notes/
- Esta máquina: tem WSL Ubuntu-26.04, mas **não** instalar Docker Engine lá (conflita com a integração do Desktop e altera o sistema do autor). Validar o que dá em contêiner descartável `ubuntu:26.04`/`ubuntu:24.04`: criar a chave e o `docker.sources`, `apt-cache policy docker-ce` (mostra a origem download.docker.com), `groupadd docker`/`usermod -aG`/`id`. Marcar systemd/daemon como não executado.

## Exemplos novos
- Usuário "ana" criado num contêiner para mostrar o efeito de `usermod -aG docker` com `id`.

## Erros comuns
- `permission denied while trying to connect to the Docker daemon socket` sem estar no grupo; esquecer de reabrir a sessão; instalar `docker.io` do Ubuntu e misturar; usar o script de conveniência em produção.
