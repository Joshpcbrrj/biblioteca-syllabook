# Dossiê c07: Seu primeiro Dockerfile (conferido em 2026-11-26)
## Fatos
- Formas shell e exec de RUN/CMD/ENTRYPOINT; exec = lista JSON. https://docs.docker.com/reference/dockerfile/
- Contexto de build = arquivos acessíveis ao build; `.dockerignore` filtra. https://docs.docker.com/build/concepts/context/
- ARG (só no build) × ENV (persiste na imagem); nunca segredos por ARG/ENV; usar secret mounts. https://docs.docker.com/build/building/variables/
- Base de referência: `python:3.14-slim` (existe hoje). API: Python só com biblioteca padrão (`http.server`, `json`), porta por `PORTA`, versão por `APP_VERSAO`, escuta em `0.0.0.0`.
- buildx v0.38.1 (aqui).
## Exemplos novos
- Escrever a API do zero; `.dockerignore` com `.git`, `__pycache__`, `.env`.
## Erros comuns
- `COPY . .` antes das dependências; CMD em forma shell; escutar em 127.0.0.1; esquecer o ponto do `docker build .`.
