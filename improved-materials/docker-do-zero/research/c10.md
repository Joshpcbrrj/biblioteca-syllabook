# Dossiê c10: Redes (conferido em 2026-11-26)
## Fatos
- Rede padrão (bridge): contêineres só se acham por IP; redes definidas pelo usuário trazem DNS por nome. https://docs.docker.com/engine/network/ e /tutorials/standalone/
- Porta publicada fica visível fora do host; não publicar o banco.
- Driver `host`: o contêiner compartilha a pilha de rede do host. https://docs.docker.com/engine/network/drivers/host/ (no Desktop pode exigir ativar nas configurações: conferir).
- `host.docker.internal`: a URL de networking do Desktop deu 404; achar a página atual antes de afirmar.
## Exemplos novos
- Rede `dz-net`; a API acha `dz-db` pelo nome; `docker network inspect --format`.
## Erros comuns
- `localhost` dentro do contêiner é o próprio contêiner; usar o IP (muda); publicar a 5432 à toa.
