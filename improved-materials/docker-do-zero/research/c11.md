# Dossiê c11: Publicar a imagem (conferido em 2026-11-26)
## Fatos
- Docker Hub: PATs e OATs servem para `docker login`. https://docs.docker.com/security/access-tokens/
- `docker login` guarda credenciais no credential store (Desktop) ou em `~/.docker/config.json`. https://docs.docker.com/reference/cli/docker/login/ (usar `--password-stdin`).
- GHCR: `ghcr.io`; GitHub Packages só autentica com token pessoal classic (`write:packages` e `read:packages`). https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-container-registry
- Tags de versão (semver) além de `latest`; o digest é imutável.
- Lab: o autor não deve colar token no chat; push real depende de conta do leitor. Executável aqui: registro local `registry:3` em `localhost:5000` (já existe `localhost:5000/stack-api:1.1` na máquina: conferir se há registro rodando, não mexer). Push ao Docker Hub: "não executado".
## Erros comuns
- Senha da conta em vez de token; `push` sem `tag` com o seu usuário; segredo dentro da imagem.
