# Dossiê c06: Imagens e o Docker Hub (conferido em 2026-11-26)
## Fatos
- Nome completo: `registro/namespace/repositório:tag` (`docker.io/library/python:3.14-slim`). Digests lidos hoje: python:3.14-slim `sha256:22eafb37…`; nginx:alpine igual a nginx:1.31-alpine `sha256:7fc0fb4a…`; ubuntu:24.04 `sha256:562111b8…` (digests mudam; citar como exemplo datado).
- Confiança: Docker Official Images, Docker Hardened Images, Verified Publisher, Docker-Sponsored Open Source. https://docs.docker.com/docker-hub/image-library/trusted-content/
- Pull sem login: 100 por 6 h por IPv4 (ou sub-rede /64 IPv6). https://docs.docker.com/docker-hub/usage/
- `docker image prune` remove só *dangling*; `-a` remove todas as sem uso (**perigoso aqui**). https://docs.docker.com/reference/cli/docker/image/prune/
- `docker save` grava tar (stdout por padrão); `docker load` lê. https://docs.docker.com/reference/cli/docker/image/save/
- Esta máquina usa o armazenamento containerd (`docker images` mostra DISK USAGE e CONTENT SIZE); `docker buildx imagetools inspect` lista plataformas.
