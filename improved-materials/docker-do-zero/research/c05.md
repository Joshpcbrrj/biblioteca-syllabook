# Dossiê c05: Docker Desktop na prática (conferido em 2026-11-26)
## Fatos
- O Dashboard reúne contêineres, imagens, volumes, builds, Kubernetes e logs; também Model Runner, Offload, Hub, Extensions. https://docs.docker.com/desktop/use-desktop/
- Desktop 4.100.0 (2026-11-19) trouxe novo visual (logo Moby, rebranding). 4.100.0 e 4.100.1 têm problema conhecido: com o armazenamento containerd, contêineres e imagens podem aparecer "sumidos" até desmarcar *Use containerd for pulling and storing images* (Settings > General). https://docs.docker.com/desktop/release-notes/ . Esta máquina roda 4.99.0: as telas do livro seguem a 4.99; avisar que o visual da 4.100 mudou.
- Contextos: `docker context ls` mostra `default` (npipe docker_engine) e `desktop-linux` (ativo) aqui; `docker context use`. https://docs.docker.com/reference/cli/docker/context/
- Licença: grátis para uso pessoal, educação, pequenas empresas (menos de 250 pessoas e menos de US$10 mi), open source não comercial; pago para o resto e governo. https://docs.docker.com/desktop/setup/install/windows-install/
- Capturas reais: pedir ao usuário (Desktop é janela): abas Containers, Images, Settings.
## Exemplos novos
- Mesma tarefa pela janela e pela CLI: iniciar `dz-api`, ver logs, terminal integrado, parar.
## Erros comuns
- Achar que interface e CLI são engines diferentes; CLI sem Desktop aberto; contexto errado.
